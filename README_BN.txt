নীল খামের শেষ চিঠি — Android App Project

এই ZIP-এ Android Studio-তে APK বানানোর জন্য প্রজেক্ট দেওয়া আছে।
এখানে বইয়ের HTML reader অ্যাপের মধ্যে যুক্ত করা হয়েছে।

APK বানানোর ধাপ:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio খুলে "Open" চাপুন।
3. ZIP extract করে Neel_Khame_Android_Project ফোল্ডারটি নির্বাচন করুন।
4. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
6. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk-এ তৈরি হবে।

নোট:
এই পরিবেশে Android SDK/Gradle build tool নেই, তাই এখান থেকে APK binary compile করা যায়নি।
এই ফাইলটি Android Studio-তে build করার মতো source project।
